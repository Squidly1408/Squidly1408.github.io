Privacy Policy

Effective 19 November 2026

The short version

  • There are no accounts, no analytics, no ads and no tracking cookies.
  • Everything you type or upload stays in your browser. It is never sent to us.
  • A few third parties are contacted automatically: GitHub (which hosts the site), Google Fonts, and the hosts of any remote images in your README preview. They can see your IP address, as with any web request.
  • You can delete everything the app has stored with one button at the bottom of this page.

1. Who we are

Readme Forge (“the app”, “we”, “us”) is a free, open-source tool for building GitHub README files. It is maintained by Lucas Newman. The source code is public at github.com/Squidly1408/ReadMe-Forge.

2. Information we collect

None. Readme Forge has no server of its own and no database, so we never receive or store your project details, README content, templates or images. We do not use analytics or tracking tools of any kind.

3. Data stored in your browser

So that your work is still there when you come back, the app saves the following in your browser's localStorage, under keys that start with rf.:

  • Project details you enter (name, tagline, GitHub username, repo, author, license)
  • Your current README draft and any templates you save
  • Logos and banners you upload or generate, and your Logo & Banner Studio settings
  • Small preferences, such as the preview theme and whether you have seen the welcome guide

This data stays on your device and is only readable by this website in your browser. It is not shared between browsers or devices. Anyone with access to your browser profile could see it, so avoid using the app for confidential material on a shared computer.

The app does not set cookies.

4. Third-party services

Using the app causes your browser to contact the services below directly. We have no control over them and do not receive any data from them. Each one can see standard request information such as your IP address, browser type and the page that made the request.

Links in your preview open in a new tab. Once you leave the app, the destination site's own privacy policy applies.

5. Downloads and clipboard

README files, .zip archives and PNG images are created on your device and saved straight to your computer. When you press Copy, the markdown is written to your clipboard by your browser. None of this passes through us.

6. Your choices and rights

Because we hold no personal data about you, there is nothing for us to access, correct, export or delete on our side. You are fully in control of the data in your browser:

  • Use the button below to delete everything Readme Forge has stored.
  • Or clear this site's data in your browser settings.
  • Your own templates can be exported to a JSON file from the Templates dialog before you clear anything.

This permanently removes your draft, saved templates, project details, images and settings from this browser. It cannot be undone.

7. Children

The app is a general-purpose developer tool and is not directed at children. It does not knowingly collect information from anyone, including children.

8. Changes to this policy

If this policy changes, the updated version will be posted on this page with a new effective date. The full history of changes is visible in the project's public repository.

9. Contact

Questions about this policy? Open an issue at github.com/Squidly1408/ReadMe-Forge/issues.
